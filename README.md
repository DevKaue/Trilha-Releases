# Trilha · instaladores

Versões públicas da **Trilha**, a ferramenta da SpaceIT que grava cenários de
teste na homologação e gera o registro de bug pronto.

O jeito mais fácil de baixar é pela página de download, que escolhe o arquivo
certo para o seu computador. Aqui ficam os mesmos arquivos de cada versão:

| Sistema | Arquivo |
|---|---|
| Windows | `Trilha_<versão>_x64-setup.exe` |
| Mac (Apple Silicon e Intel) | `Trilha_<versão>_universal.dmg` |
| Ubuntu, Debian e Mint | `Trilha_<versão>_amd64.deb` |
| Qualquer Linux | `Trilha_<versão>_x86_64.AppImage` |

[Baixar a versão mais recente](https://github.com/DevKaue/Trilha-Releases/releases/latest)

Os arquivos são gerados automaticamente pelo GitHub Actions a partir do
repositório privado do projeto. Este repositório não tem código-fonte.

## Primeira abertura

- **Windows:** se aparecer "O Windows protegeu o computador", clique em
  Mais informações › Executar assim mesmo.
- **Mac:** abra Ajustes do Sistema › Privacidade e Segurança e clique em
  Abrir Mesmo Assim ao lado do aviso da Trilha.
- **AppImage:** em Propriedades, marque Permitir executar como programa.
