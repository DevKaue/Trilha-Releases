# Segurança

Encontrou um problema de segurança na Trilha? Não abra uma issue pública.
Use a opção **Report a vulnerability** na aba Security deste repositório
para falar direto com quem mantém o projeto.

A Trilha guarda sessões, prints e bugs só no computador de quem testa.
CPF e CNPJ são mascarados antes de salvar, e campos de senha nunca são gravados.
